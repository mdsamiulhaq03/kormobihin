Fix: seed realistic Dhaka hours, seed the 3 documented matches, hide Match column when none checked. Command: /impeccable harden
2. [P1] Brand voice absent, rejection treated as deletion: no use of the name, "Mark as rejected" + confirm styled destructive like Delete, cold copy, no support after; Offer/Accepted get the same flat toast. Fix: explain the name gently on landing/empty states; neutral styling + encouraging line + active count after rejection; distinct Offer/Accepted moment; no jokes on bad news. Command: /impeccable delight then /impeccable clarify
3. [P1] Board hides half the pipeline and bypasses rules UX: 8×256px columns in max-w-6xl, exits off-screen at 1366; Move menu skips confirm+note; every Move button announced "Move to another stage". Fix: collapse Rejected/Declined into "Closed", full-bleed board, route moves through the confirm dialog, aria-label with company. Command: /impeccable layout
4. [P2] Dashboard has no next action; flags don't nudge: six equal cards; "No response" without "Follow up with Grameenphone (25 days)"; "Next 7 days" third on mobile; chart labels collide at 390px; legend text 1.8:1. Fix: "Today" strip merging interviews + flags with verb-first actions, demote Pipeline, one-line chart takeaway, fix legend contrast. Command: /impeccable distill
5. [P2] Capture is slow for "never lose an application": JD required ≥30 chars (FB posts are images), 7 optional fields always open, status choice buried, Wishlist default, placeholders look like values. Fix: quick add (company + title + status first), JD optional with "add later to unlock CV match", collapse details, "e.g." placeholders. Command: /impeccable onboard
